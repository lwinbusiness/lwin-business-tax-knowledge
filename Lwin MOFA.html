FAQ

မေးလေ့ရှိသော မေးခွန်းများ

Educational Certificate fee ဘယ်လောက်လဲ?

ပေးထားသော fee table အရ UAE မှထုတ်သည်ဖြစ်စေ UAE ပြင်ပမှထုတ်သည်ဖြစ်စေ AED 150 ဖြစ်သည်။ Courier fee သီးခြားရှိနိုင်သည်။

Commercial document fee ဘယ်လောက်လဲ?

ပေးထားသော commercial fee table အရ document အများစု AED 2,000 ဖြစ်သည်။ “Document Attested outside” entry တစ်ခုကို AED 150 အဖြစ်ပြထားသည်။

Application တစ်ခုထဲ document အများကြီးထည့်လို့ရလား?

Official guide အရ document တစ်ခုထက်ပို၍ application တစ်ခုအတွင်း ထည့်နိုင်သည်။

Original document ကို courier ပေးရမလား?

Guide တွင် courier agent ထံ document(s) ပေးပြီး pickup/delivery service ဖြင့်ပြန်ပို့မည်ဟုဖော်ပြထားသည်။ သင့် document type အတွက် original requirement ကို portal တွင် ထပ်စစ်ပါ။
